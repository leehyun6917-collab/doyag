# index.html (홈) 텍스트 전체 정리

## 헤더 / 내비게이션

- 로고 텍스트: **청춘 도약 일자리교육원**
- 메뉴: 홈 / 구직청원휴가 안내 / 상담 신청 / 취업연계 프로그램 / 자주 묻는 질문 / 오시는 길·문의
- 헤더 CTA 버튼: **상담 신청하기**
- 모바일 메뉴 버튼 라벨(스크린리더용): "메뉴 열기"
- 본문 바로가기 링크: "본문으로 바로가기"

## 1. 히어로

- 배지: 현역 장병 전용 상담 프로그램
- **H1**: 휴가 하루도 아깝지 않은, 확실한 구직청원휴가 상담
- 본문: 의무복무 50% 이상이면 신청할 수 있어요. 서류 준비부터 취업 연계까지, 청춘 도약 일자리교육원이 처음부터 끝까지 함께 안내해 드립니다.
- 버튼: 상담 신청하기 / 3초 자가진단 먼저 하기
- 태그: 대면·비대면 선택 가능 / 지휘관 제출용 서식 안내 / 투명한 비용 공개

## 2. 신뢰 요소 (통계 카드 4개)

| 값 | 라벨 |
|---|---|
| 50% | 복무율만 넘으면 신청 가능 |
| 2가지 | 대면 · 비대면 상담 방식 |
| 1:1 | 맞춤형 개별 상담 진행 |
| 투명 | 숨은 비용 없는 사전 안내 |

## 3. 고민 공감

- eyebrow: 이런 걱정, 당연합니다
- H2: 상담 신청 전에 이런 고민 없으셨나요?
- 설명: 소중한 휴가를 쓰는 만큼 신중해야 하는 게 당연합니다. 청춘 도약은 그 걱정을 하나씩 없애드립니다.

| 아이콘 | 카드 제목 | 카드 설명 |
|---|---|---|
| 🔍 | 이 업체, 믿어도 될까? | 누구에게 상담받는지 확실히 알고 싶은데 정보가 부족해 불안하셨을 거예요. |
| 📋 | 지휘관님이 승인해 주실까? | 부대에 제출할 서류가 형식에 맞는지, 승인이 될지 걱정되실 수 있어요. |
| 💳 | 비용이 얼마나 나올지 모르겠다 | 상담 전에 정확한 비용을 알 수 없어 망설여지는 경우가 많습니다. |

## 4. 해결책

- eyebrow: 청춘 도약의 방식
- H2: 그 걱정, 이렇게 해결합니다

| 아이콘 | 카드 제목 | 카드 설명 |
|---|---|---|
| 🪪 | 투명한 상담 정보 공개 | 상담을 진행하는 기관과 담당자 정보를 신청 전에 명확히 안내해 드려요. |
| 📄 | 서식을 미리 보여드려요 | 부대 제출용 상담 확인 서식을 신청 전 미리 확인하실 수 있습니다. |
| 💻 | 방식은 자유롭게 선택 | 화상·전화·대면 상담 중 편한 방식을 직접 선택할 수 있습니다. |
| 🧾 | 비용을 먼저 확인하세요 | 상담 신청 페이지에서 방식별 비용을 표로 투명하게 안내해 드립니다. |

## 5. 이용 절차 (5단계)

- eyebrow: 이용 절차
- H2: 신청부터 서류 전달까지 5단계

1. **지휘관 확인** — 상담 전, 소속 부대 지휘관에게 구직청원휴가 사용 가능 여부를 먼저 확인하세요.
2. **상담 신청** — 원하는 날짜와 상담 방식(대면·비대면)을 선택해 신청서를 남겨주세요.
3. **신청 확인 안내** — 필요한 경우 상담 예정 확인 서식을 미리 안내해 드립니다.
4. **1:1 상담 진행** — 예약된 일정에 맞춰 진로·취업·창업 상담을 진행합니다.
5. **증빙자료 전달** — 상담 완료 후 부대 제출용 확인 자료를 전달해 드립니다.

## 8. FAQ 요약 (5문항)

1. **구직청원휴가란 무엇인가요?** — 의무복무 중인 현역 장병이 취업 준비를 위해 사용할 수 있는 법정 특별휴가예요. 군인의 지위 및 복무에 관한 기본법 시행령 제12조에 근거합니다.
2. **누가 신청할 수 있나요?** — 의무복무기간의 50% 이상을 마친 병사, 그리고 전역예정일이 1년 이내인 단기복무 장교·부사관이 신청할 수 있어요.
3. **최대 며칠까지 사용할 수 있나요?** — 병사는 최대 2일이며, 간부는 복무기간에 따라 최대 사용 일수가 달라질 수 있어요.
4. **비대면 상담도 가능한가요?** — 네, 화상 또는 전화 상담을 지원하고 있어 원격지 부대에서도 편하게 이용하실 수 있어요.
5. **비용은 얼마인가요?** — 상담 신청 페이지에서 대면·비대면 방식별 비용을 표로 투명하게 안내해 드리고 있어요.

## 아직 확정되지 않은 부분 (검토 필요)

- 헤더/모든 CTA가 `apply.html`로 연결되는데, `apply.html`의 실제 제출 버튼은 카카오채널 링크가 `href="#"` placeholder 상태 — 실제 채널 URL 확정 필요
- 신뢰 요소 통계는 "실적 수치"가 아니라 서비스 특징(50%, 2가지, 1:1, 투명)으로 구성됨 — 실제 운영 데이터가 쌓이면 "누적 상담 건수" 등으로 교체 검토 가능
- 사업자등록번호 미기재 상태
