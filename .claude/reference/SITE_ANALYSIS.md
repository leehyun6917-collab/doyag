# 참고 사이트 분석 (Firecrawl)

REFERENCE.md의 대표 URL 3개를 Firecrawl(map/scrape)로 분석한 결과. 레이아웃·구조·인터랙션 패턴만 참고하고, 실제 문구·이미지·후기는 자사 콘텐츠로 새로 작성한다.

## 1. Map 결과

- `miliconnectlink.imweb.me/koreaspringsoldier` — 단일 랜딩페이지 (하위 URL 없음)
- `seongo.kr` — 에이전시 본사이트 산하에 다수의 캠페인 랜딩페이지가 존재. 이번 분석과 관련된 페이지는 `koreaspringsoldierbasic`(군인 상담실), `koreaspringsoldier`(비대면 신청), `kmilitaryjob`(채용 버스킹) 3개이며, `/about`, `/portfolio-view`, `/shop_view/*` 등은 에이전시 자체 서비스 소개 페이지로 이번 분석 대상이 아님.

## 2. 페이지별 제목 · 핵심 콘텐츠 구조

### 메인 페이지 — `miliconnectlink.imweb.me/koreaspringsoldier`
- **제목(H1 요지)**: 안전한 구직청원휴가 안내
- **섹션 흐름**: 미니멀 헤더(로고만) → 히어로(배지+H1+서브카피+단일 CTA) → 문제 제기 3카드(피해야 할 업체 유형) → 신뢰 비교(경쟁사 vs 자사 강점 4카드) → 5단계 프로세스 → 지역 지점 5카드 → FAQ 아코디언(5문항) → 최종 CTA → 푸터(연락처/지점/위기상담 핫라인)

### 군인 상담실 — `seongo.kr/koreaspringsoldierbasic`
- **제목(H1 요지)**: 구직청원휴가 신청 안내
- **섹션 흐름**: 풀 헤더(로고+4단 GNB) → 히어로(배지+H1+4개 피처 아이콘+CTA) → 제도 설명 Q&A 3카드 → 5단계 프로세스 → **2단계 인터랙티브 자가진단 퀴즈**(복무율/목적 선택 → 대상 여부 분기 결과 + CTA) → 크로스셀 섹션(채용 버스킹 소개 4카드 + 이동 CTA) → FAQ 아코디언(6문항, +/- 토글) → 푸터

### 채용 버스킹 — `seongo.kr/kmilitaryjob`
- **제목(H1 요지)**: 국군장병 채용 버스킹 안내
- **섹션 흐름**: 풀 헤더(로고+4단 GNB) → 히어로(라벨+H1+서브카피, CTA 없이 스크롤 유도) → 참여 이유 3카드(번호형 01/02/03) → 법적 근거 섹션(라벨+조문 인용 박스) → FAQ 아코디언(5문항, Q/A 라벨형) → 최종 CTA(버튼 2개) → 푸터

## 3. CTA 버튼 문구

| 페이지 | 위치 | 문구(원문 — 참고용, 자사 문구로 교체 필요) | 연결 대상 |
|---|---|---|---|
| 메인 | 히어로 | "1분 만에 상담 예약하기" | 카카오채널 |
| 메인 | 하단 FAQ 뒤 | "바로 예약하러가기" | 카카오채널 |
| 군인 상담실 | 히어로 | "구직청원휴가 1:1 상담받기" | 카카오채널 |
| 군인 상담실 | 자가진단 결과 | "지금 바로 1:1 상담 예약하기" | 카카오채널 |
| 군인 상담실 | 크로스셀 | "국군장병 채용 버스킹 신청하기 →" | 채용 버스킹 페이지(내부 이동) |
| 채용 버스킹 | 최종 CTA(주) | "채용 버스킹 일정 예약하기" | 네이버 예약 |
| 채용 버스킹 | 최종 CTA(보조) | "일정 예약 하러 가기" | 네이버 예약 |

**패턴**: 모든 CTA가 단일 전환 채널(카카오채널 상담 예약 or 네이버 예약)로 귀결되며, 문구는 "행동 + 시간/난이도 완화 표현"(예: "1분 만에", "지금 바로") 조합을 반복 사용.

## 5. 자사 홈페이지 적용 제안 (REFERENCE.md "참고할 요소" 매핑)

| 참고할 요소 | 관찰된 패턴 | 자사 적용 제안 |
|---|---|---|
| 헤더 높이·메뉴 배치 | 캠페인 서브페이지는 로고+4단 수평 GNB, 랜딩페이지는 로고만 있는 미니멀 헤더 | 메인 홈은 풀 GNB, 단일 목적 캠페인/이벤트 페이지는 로고만 있는 미니멀 헤더로 페이지 성격에 따라 헤더를 분리 구성 |
| 히어로 텍스트·이미지 비율 | 사진 없이 배지 라벨 + 굵은 H1 + 서브카피 + 단일 CTA만으로 구성된 타이포 중심 히어로 | 초기 단계에 이미지 리소스 없이도 완성도 있게 보이도록 타이포그래피 중심 히어로 구조 채택 가능 |
| 섹션별 배경색 구분 | 마크다운만으로는 실제 색상 값 확인 불가 (문제제기/비교/프로세스/지점/FAQ 등 블록은 구분되어 있음) | 색상 팔레트는 스크린샷(`home-desktop.png` 등) 확보 후 별도 색상 추출 작업 필요 — 현재 저장소에 해당 이미지 자료 없음 |
| 카드 모서리·테두리 | 위와 동일하게 마크다운으로 확인 불가 | 스크린샷 확보 후 카드 스타일(radius/border/shadow) 분석 추가 필요 |
| CTA 버튼 구조 | 전 페이지가 "문제 제기 → 신뢰 강조 → 프로세스 → FAQ" 뒤 동일한 단일 전환 채널로 반복 CTA 배치 | 자사도 하나의 명확한 전환 채널(예: 카카오채널/폼)을 정하고, 히어로·중간·FAQ 하단에 동일 CTA를 반복 배치 |
| 모바일 쌓임 순서 | 히어로 → 문제제기 → 신뢰요소 → 프로세스 → (인터랙티브 진단) → 크로스셀/지점 → FAQ → 푸터 | 이 순서를 기본 골격으로 채택하고, "군인 상담실" 페이지의 2단계 자가진단 퀴즈처럼 사용자 참여형 인터랙션 섹션(간단 체크리스트/자가진단) 도입을 검토 |
